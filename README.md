# AI SUBMEDIA

ابزار شخصی برای تبدیل صوت به متن (Whisper) و ساخت/ترجمه زیرنویس SRT به فارسی.

## ساختار پروژه (نسخه بازنویسی‌شده)

```
index.html          صفحه اصلی (فقط ساختار HTML)
style.css           استایل‌ها (قبلاً داخل main.html بود)
js/
  utils.js          توابع کمکی مشترک (فرمت زمان SRT، دانلود فایل، ساخت امن <option>)
  config.js         مدیریت پروایدرها/کلیدهای API در localStorage
  srt.js            تجزیه و بازسازی فایل SRT
  translate.js       ترجمه گوگل + ترجمه هوشمند (batch/concurrency/retry)
  transcribe.js       آپلود صوت و تبدیل به متن
  ui.js             اتصال DOM، تب‌ها و فرم‌ها به ماژول‌های بالا
  main.js           نقطه شروع
api/
  index.py          بک‌اند Flask (پروکسی ترجمه گوگل + ترجمه هوشمند + مسیر legacy)
vercel.json
requirements.txt
```

قبلاً همه‌چیز (HTML+CSS+JS) در یک فایل `main.html` بود چون `vercel.json` قدیمی
هر مسیری غیر از `/` را به تابع پایتون rewrite می‌کرد و فایل استاتیک دیگری سرو
نمی‌شد. در این نسخه `vercel.json` فقط مسیرهای API را rewrite می‌کند، بنابراین
Vercel می‌تواند `style.css` و فایل‌های داخل `js/` را به‌صورت مستقیم (و سریع‌تر،
چون از تابع سرورلس عبور نمی‌کنند) سرو کند.

## دیپلوی

۱) کل این پوشه (`index.html`, `style.css`, `js/`, `api/`, `vercel.json`,
   `requirements.txt`) را روی Vercel دیپلوی کنید.
   متغیر محیطی مورد نیاز:
   - `GROQ_API_KEY` — فقط برای مسیر legacy پشتیبان `/transcribe-aac` لازم است
     (فرانت‌اند فعلی از آن استفاده نمی‌کند؛ می‌توانید تنظیمش نکنید).

   متغیرهای محیطی اختیاری:
   - `AI_PROXY_WORKER` — آدرس ورکر چندپروایدری (پیش‌فرض:
     `https://ai-reverse.aialsabela.workers.dev`)
   - `ALLOWED_ORIGINS` — اگر می‌خواهید از دامنه‌ی دیگری هم به این API درخواست
     بزنید، دامنه‌ها را با کاما جدا کنید. به‌صورت پیش‌فرض فقط درخواست هم‌مبدأ
     مجاز است (نیازی برای استفاده عادی از این پروژه نیست).

۲) `worker.js` (اگر دارید) روی Cloudflare Workers دیپلوی می‌شود، نه Vercel، و
   جدا از این پروژه است.

## تغییرات نسخه بازنویسی‌شده نسبت به نسخه قبلی

**امنیت**
- محافظت در برابر SSRF: قبل از هر تماس خروجی سرور به آدرس پروایدر (که کاملاً
  کاربر تعیین می‌کند)، آدرس بررسی می‌شود — فقط https، و بدون امکان اشاره به
  IPهای داخلی/loopback/link-local.
- CORS دیگر برای همه دامنه‌ها باز نیست (`ALLOWED_ORIGINS` پیش‌فرض خالی =
  فقط هم‌مبدأ)، چون همه درخواست‌های فرانت‌اند اصلاً هم‌مبدأ هستند.
- `debug=True` حذف شد (اجرای دیباگر Werkzeug در دسترس عموم ریسک اجرای کد
  دلخواه دارد).
- محدودیت حجم بدنه درخواست و محدودیت تعداد/طول متن‌های هر درخواست ترجمه —
  جلوگیری از سوءاستفاده/اتمام منابع.
- جلوگیری از XSS در رابط کاربری: مقادیر (نام پروایدر، برچسب کلید، ...) دیگر
  با الحاق رشته در `innerHTML` رندر نمی‌شوند؛ از DOM API امن (`textContent`)
  استفاده می‌شود.
- جلوگیری از prototype pollution هنگام «بازیابی» فایل پشتیبان JSON.
- دامنه‌ی نادرست ورکر در مسیر legacy `/transcribe-aac` که با `AI_PROXY_WORKER`
  اصلی ناهماهنگ بود، اصلاح شد.

**کیفیت کد**
- تفکیک HTML/CSS/JS به فایل‌های جداگانه با مسئولیت مشخص (به‌جای یک فایل
  ۱۴۰۰ خطی).
- ماژول‌های ES (`import`/`export`) به‌جای یک اسکوپ全global بزرگ.
- استفاده از `logging` به‌جای `print` در بک‌اند.

**سرعت**
- فایل‌های استاتیک (CSS/JS) اکنون مستقیماً توسط CDN ورسل سرو می‌شوند، نه از
  طریق تابع سرورلس پایتون.
- درخواست‌های شبکه سمت کلاینت با `AbortController` تایم‌اوت واقعی دارند، پس
  در صورت هنگ شبکه رابط کاربری برای همیشه گیر نمی‌کند.

**کارکرد**
- همه‌ی قابلیت‌های قبلی (آپلود/لینک صوت، ترجمه گوگل، ترجمه هوشمند با
  batch+concurrency+retry، مدیریت پروایدر/کلید، پشتیبان‌گیری/بازیابی) دقیقاً
  حفظ شده‌اند.
